기존 영역 캡처 기능을 버전 1.4.1로 다시 배포합니다.

1. `element-inspector-1.4.1.zip`을 받아 압축을 풉니다.
2. 기존 설치 폴더를 새 파일로 교체한 뒤 `chrome://extensions`에서 **엘리먼트 검사기**의 새로고침 버튼을 누릅니다. 처음 설치하는 경우 **개발자 모드**를 켜고 **압축해제된 확장 프로그램 로드**에서 `manifest.json`이 있는 폴더를 선택합니다.
3. 엘리먼트 검사기 버전이 **1.4.1**인지 확인합니다. 일반 웹페이지를 새로고침한 후 Windows에서는 **Alt+Shift+W**, Mac에서는 **Option+Shift+W**를 누르고 캡처할 영역을 드래그합니다.

단축키가 반응하지 않으면 `chrome://extensions/shortcuts`에서 **엘리먼트 검사기 → 영역 캡처**에 등록된 키를 확인하세요.
