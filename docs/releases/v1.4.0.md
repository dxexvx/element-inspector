- **영역 캡처** — 웹페이지에서 **Alt+Shift+W**(Mac에서는 **Option+Shift+W**)를 누르고 원하는 영역을 드래그하면 PNG가 클립보드에 복사됩니다. Picklog PAT와 프로젝트를 저장한 경우 같은 PNG를 캔버스에도 저장합니다.
- **요소 캡처** — 현재 페이지의 리소스가 계속 로딩 중이어도 화면에 보이는 요소를 캡처할 수 있습니다. 탭이 전환되거나 화면의 선택 위치가 바뀌면 캡처를 중단합니다.

## 설치

`element-inspector-1.4.0.zip`을 내려받아 압축을 풉니다. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 눌러 `manifest.json`이 있는 폴더를 선택합니다. 설치 후 웹페이지를 새로고침합니다.

기존 설치는 같은 폴더에서 파일을 교체한 뒤 Chrome 확장 목록에서 **새로고침**을 누릅니다.
