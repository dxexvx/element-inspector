엘리먼트 검사기 개인정보처리방침

최종 수정: 2026년 10월 26일 · 적용 대상: 엘리먼트 검사기 1.2.1

엘리먼트 검사기는 사용자가 웹페이지의 요소를 선택하여 수정 위치를 설명하는 데 필요한 정보를 클립보드에 복사하는 도구입니다. 개발자 서버나 에이전트로 정보를 자동 전송하지 않습니다.

처리하는 정보와 목적

검사 모드에서는 포인터 아래 요소를 강조하고 태그·id·class·CSS 식별자를 표시하기 위해 해당 요소를 읽습니다. 사용자가 요소를 클릭하면 설정에서 선택한 항목만 복사합니다. 선택 가능한 항목은 현재 페이지 URL, 문서 제목, 영역 제목, 요소 텍스트, 항목 텍스트, 요소 이름, 요소 태그, id, class, CSS, 프레임 주소입니다. 페이지 URL은 현재 문서의 주소이며 브라우저 전체 방문기록 목록을 읽지 않습니다.

단축키 감지, 대상 선택, 취소와 복사를 위해 키보드·포인터·클릭 이벤트를 브라우저 안에서 처리합니다. 키 입력 내용이나 사용자 활동 이력을 기록하거나 전송하지 않습니다. 포인터 위치는 현재 검사 대상을 표시하는 데 사용합니다.

입력칸·선택칸·편집 가능한 영역의 입력값은 렌더링된 텍스트를 읽는 과정에서 제외합니다. 페이지 URL의 사용자명·비밀번호와 알려진 인증 관련 query/hash 인자도 제외합니다. 이 처리는 모든 민감정보를 제거하는 기능이 아닙니다. 웹페이지의 표시 내용, 제목, 접근성 이름, URL 경로와 기타 인자, id·class·CSS에는 개인정보나 비밀값이 있을 수 있습니다. 사용자는 복사할 항목을 줄이고 붙여넣기 전에 내용을 확인할 수 있습니다.

저장과 보유 기간

단축키·복사 항목 선택은 이 브라우저의 확장 로컬 저장소에 보관되며 기기간 동기화 기능을 사용하지 않습니다. 기본값 복원 후 저장하면 초기 설정으로 바뀝니다. 확장을 제거하면 Chrome이 관리하는 해당 확장 저장소도 제거됩니다.

탭별 검사 켜짐 상태는 임시 세션 저장소에 보관합니다. 페이지 로딩·탭 닫기 시 정리하며 브라우저 세션 종료 또는 확장 다시 로드 등의 경우 초기화됩니다. 포인터·강조·복사문 생성에 필요한 정보는 동작 중 일시적으로 처리합니다. 페이지 내용이나 복사 이력을 확장 저장소에 저장하지 않습니다.

복사 결과는 운영체제의 클립보드에 남습니다. 다른 내용을 복사하거나 운영체제의 클립보드 관리 기능으로 정리할 수 있습니다. 클립보드 기록과 기기간 동기화를 켠 경우 운영체제 또는 클립보드 관리 앱이 그 내용을 보관·동기화할 수 있습니다. 이는 해당 기능의 설정과 정책을 따릅니다. 확장 제거가 운영체제 클립보드 기록까지 지우지는 않습니다.

전송·제3자 제공·광고

이 확장 자체는 선택한 페이지 내용, URL, 설정, 복사 결과와 활동 데이터를 개발자 서버나 외부 서비스로 전송하지 않습니다. 제3자 분석 SDK·광고·추적·계정 로그인·데이터 판매 기능이 없습니다. 개발자는 확장을 통해 사용자의 페이지 정보나 복사 내용을 전달받거나 열람하지 않습니다.

사용자가 복사문을 에이전트·메신저·다른 웹사이트에 직접 붙여넣는 경우 그 서비스의 정책과 권한이 적용됩니다. 확장은 붙여넣을 외부 서비스를 선택하거나 자동 전송하지 않습니다.

권한과 사용자 제어

사이트 접근 권한은 HTTP·HTTPS 웹페이지 및 지원되는 프레임에서 설정한 단축키를 감지하고 요소를 검사하기 위해 사용합니다. 클립보드 쓰기 권한은 사용자가 선택한 정보를 복사하는 데 사용하며 기존 클립보드를 읽지 않습니다. 저장소 권한은 위 설정과 임시 검사 상태에 사용합니다.

사용자는 복사 항목을 개별 선택하고, Esc로 검사를 중단하고, Chrome 확장 세부정보에서 사이트 접근을 제한하거나 확장을 끄고 제거할 수 있습니다. 사이트 접근을 제한하면 허용되지 않은 사이트에서는 단축키·검사가 작동하지 않을 수 있습니다. 최소 한 개의 복사 항목은 선택해야 합니다.

제한된 사용과 변경 안내

이 확장에서 처리하는 정보는 공개한 요소 검사·복사 기능을 제공하는 데만 사용합니다. Chrome 웹 스토어 사용자 데이터 정책과 제한된 사용 요구사항을 준수하며 광고 타기팅, 데이터 판매, 신용도 평가나 대출 판단에 사용하지 않습니다. 데이터 처리 방식이 바뀌면 방침을 갱신하고 필요한 사전 안내와 동의를 제공합니다.
