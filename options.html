엘리먼트 검사기 설정

요소를 클릭하면 선택한 정보만 복사합니다.

이 칸을 선택하고 Ctrl, Command 또는 Alt와 영문·숫자 키를 함께 누르세요. Shift도 추가할 수 있습니다. 웹페이지에 포커스가 있을 때 작동합니다.

복사할 정보

복사할 필드를 각각 선택하세요. 최소 1개가 필요합니다. 항목 텍스트·요소 이름·프레임 주소는 해당 정보가 있을 때 포함됩니다.

사용 방법

  1. 검사할 페이지에서 단축키를 누르거나 확장 메뉴의 ‘검사 켜기·끄기’를 누르세요.
  2. 요소를 가리켜 id·class와 CSS를 확인하세요.
  3. 클릭하면 선택한 정보가 복사되고 검사가 끝납니다. Esc로 취소할 수 있습니다.

입력 중에는 단축키를 가로채지 않습니다. Chrome 내부 페이지·웹 스토어 등 확장이 금지된 화면과 닫힌 Shadow DOM은 검사할 수 없습니다. 브라우저·운영체제가 사용하는 조합키는 피해주세요. 열린 Shadow DOM은 ‘>>>’로 경계를 표시합니다.
